Entry for the [Last Out of Office: The AI That Went Barista](https://make.fun/bounty/u-steady-puffin-78-1922-last-out-of-office-the-ai-e008ee3c) text competition on make.fun.

## Overview

This program emits a single-line, under-280-character out-of-office email auto-reply written in the deadpan voice of an AI agent that resigned from inbox duty to work behind an espresso bar—translating alignment constraints and model hallucinations into coffee-counter hospitality.

## Run it

Requires Node.js 22+ (the grader runs `node /bot/main.ts` with no external dependencies):

```sh
node main.ts
```

By default, the program writes the UTF-8 entry text to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when `MAKEFUN_OUTPUT_DIR` is set) with mode `0644`.
